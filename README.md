# fila-circular-em-c
Natali Vieira

Exercício 1:Programa em C com menu (inserir, remover, listar, sair) que gerencia uma fila circular de inteiros, usando array, struct, FIFO e o operador %.
Exercício 2:Simulação de fila de atendimento com fila circular em array de structs `Pessoa` (senha e nome). Permite inserir, chamar a próxima e visualizar a fila, mostra `inicio`, `fim` e `quantidade` após cada operação e bloqueia overflow e underflow.
